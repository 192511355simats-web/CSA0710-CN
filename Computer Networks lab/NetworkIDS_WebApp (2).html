About the Project

Network Intrusion Detection System Using Machine Learning

Introduction

Network Intrusion Detection Systems (NIDS) are critical components of modern cybersecurity infrastructure. This capstone project implements a machine learning-based NIDS using the Random Forest algorithm, trained on the CICIDS2017 benchmark dataset to detect various types of network intrusions with 99.98% accuracy.

Problem Statement

Traditional signature-based intrusion detection systems fail to detect zero-day attacks and novel attack patterns. As network traffic grows exponentially, manual monitoring becomes infeasible. There is a critical need for automated, intelligent systems that can analyze vast amounts of network data and identify malicious activities with high precision and low false-positive rates.

Objectives

  • Design and implement a machine learning-based network intrusion detection system
  • Train a Random Forest classifier on the CICIDS2017 benchmark dataset
  • Achieve high accuracy, precision, recall, and F1-score in attack classification
  • Build a professional web interface for real-time CSV-based traffic analysis
  • Provide actionable alerts with severity levels and recommended responses
  • Visualize results through interactive charts and dashboards

Scope

  • Binary classification: Benign vs. Attack traffic
  • Support for CICIDS2017 CSV format (78 network flow features)
  • Detection of DDoS, Port Scan, Brute Force, Web Attacks, and Infiltration
  • Batch processing of uploaded CSV files (no real-time packet capture)
  • Web-based dashboard accessible via standard web browsers

Future Enhancements

  • Real-time packet capture integration via Scapy/PyShark
  • Deep Learning models (LSTM, Autoencoder) for anomaly detection
  • Multi-class classification for specific attack type identification
  • Integration with SIEM systems (Splunk, Elastic SIEM)
  • Automated threat response and IP blocking via firewall API
  • Federated learning for privacy-preserving distributed detection
